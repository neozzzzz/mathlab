# AF-1151 시간 3 — 스크린샷 전 유형 세트 문제지 설계

## 의도
교재 「유형 뽀개기」 두 펼침면(문제 429~450, 22문항, 단원 089~094 시각과 시간)에 나온 모든 문제 유형을
숫자·상황을 바꿔 생성한다. 22문항 한 묶음을 "세트"로 보고, 세트 수만큼 인쇄하면 장수와 문제 수가
같은 비율로 늘어난다(1세트 = N장이면 2세트 = 2N장, 문제 2배).

## 목표 / 비목표
- 목표: 스크린샷의 22개 문항 형식 모두 지원, 쉬운 유형부터 어려운 유형 순으로 배치, 세트 단위 인쇄
- 비목표: 형식별 선택, 정답지, 기존 `시간`·`시간 2` 메뉴 변경
- 실패 기준: 문항이 페이지를 넘쳐 잘림, 정답이 성립하지 않는 숫자(예: 거울 시계가 정시), 세트마다 장수가 달라짐

## 접근
1. 기존 `/time2`에 형식 추가 — 시간2는 다른 교재 단원(걸린 시간 6문제 한 장)이라 설정 화면 의미가 섞임
2. 새 메뉴 `/time3`(시간 3) — 기존 시간·시간2를 티켓마다 새 메뉴로 낸 흐름과 같음 **(선택)**
3. 화면에서 높이를 재서 페이지를 나누는 방식 — 인쇄·미리보기가 달라질 수 있어 제외, 시간2처럼 형식별 예상 높이로 미리 나눔

## 정한 사항
- 세트 = 22문항 고정 순서. 예상 높이로 왼쪽 열→오른쪽 열→다음 장 순서로 채워 세트 장수를 고정한다.
- 세트 수 1~5. 설정 화면에 "1세트 = N장 · 22문제", "총 N×세트 장 · 22×세트 문제" 표시.
- 문항 번호는 세트마다 1부터, 점수 칸은 세트 첫 장에만 둔다.
- 난이도 순서: 시각 읽기(설명하는 시각) → 몇 시 몇 분 전·시각 비교 → 거울에 비친 시계 → 시간과 분 관계
  → 시간 비교 → 걸린 시간 → 끝난 시각 시계에 그리기 → 서술형.
- 답 칸은 교재처럼 오른쪽 아래 `[        ]` 괄호. 잇기·시계 그리기 문항은 답 칸 없음.
- 거울 시계는 시계 그림을 좌우로 뒤집어 그린다(숫자도 뒤집힘, 교재와 같음).
- 같은 주소는 같은 문제, 세트마다 다른 숫자(기존 seed 방식).
